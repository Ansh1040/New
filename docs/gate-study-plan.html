How the planning index is calculated

Score = 100 x (0.50 normalized recent marks/paper + 0.25 normalized recent questions/paper + 0.15 recent paper coverage + 0.10 trend component). Trend component = clip(0.5 + relative questions/paper growth, 0, 1).

Normalize recent marks and questions by the largest corresponding value among the nine core subjects. Coverage = fraction of recent papers containing the subject. Growth = (recent Qs/paper ÷ baseline Qs/paper) − 1. Clipping prevents growth contributing more than ten index points. The index is not a likelihood, a score forecast or expected marks.

For chapter rankings, normalize within the subject. When the baseline has fewer than five questions, use neutral trend = 0.5, rather than rewarding a large percentage from a tiny count. Unassigned, historical and out-of-scope buckets are not ranked.

The timetable adds prerequisite and minimum-coverage constraints, then rounds hours into usable blocks. It is not a pure proportional allocation of the index. GA and Maths get fixed daily practice instead of competing with the nine core subjects.

When to move on

Aim for at least 70% accuracy in a fresh timed set of around 20 questions and be able to explain the method without notes. This is an operational study target, not a proven cutoff. If you miss it, use the next subject block’s first hour for repair; keep the daily total at six hours. If still weak, flag it for January rather than repeatedly restarting the whole course.

Keep one question bank and one test series. Do not chase an arbitrary question quota: a reasoned solution, a recorded error and a successful reattempt matter more than rapid answer checking.

Worked example: COA priority index

Baseline frequency = 30/7 = 4.286 questions/paper. Recent frequency = 44/8 = 5.50. Growth = (5.50 / 4.286 − 1) = 28.33%. Recent marks = 72/8 = 9.00 per paper.

Among the nine core subjects, the largest recent mark average is 9.125 and the largest question average is 5.75. COA coverage is 8/8. Trend component = 0.5 + 0.2833 = 0.7833.

Index = 100 × [0.50 × (9/9.125) + 0.25 × (5.5/5.75) + 0.15 × 1 + 0.10 × 0.7833] = 96.1. Its timetable remains six days because prerequisites and all-subject coverage also constrain the plan.
